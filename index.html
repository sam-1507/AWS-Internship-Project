🏛️ AWS Architecture Overview

College Capstone

When deployed to AWS, this application is hosted on an Ubuntu 22.04 EC2 instance in a custom Amazon VPC. Web access logs are analyzed using Python and automatically archived to an Amazon S3 private bucket. Amazon CloudWatch continuously monitors CPU load and sends automated email alerts via Amazon SNS if CPU utilization exceeds 70%.

Custom VPC: 10.0.0.0/16 EC2 Ubuntu (Apache 2.4) Amazon S3 Storage IAM Roles (No Hardcoded Keys) 100% Free Tier Compliant
